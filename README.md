# Login Form (Login-Form-90)

A clean, modern login form built with plain HTML, CSS, and JavaScript.

![Preview](https://raw.githubusercontent.com/BinaryVortex/Login-Form-90/main/Screenshot%202024-08-03%20175326.png)

## Overview

This repository contains a simple, responsive login form designed as a frontend template and learning example. The form demonstrates layout, styling, and basic client-side validation using vanilla JavaScript.

## Languages

- CSS — 54.3%
- HTML — 45.7%

## Features

- Modern, centered login UI with a background image
- Responsive layout for different screen sizes
- Client-side validation example (check for empty fields)
- Easy to customize and integrate into other projects

## Files

- `index.html` — Login form markup
- `style.css` — Styling for the form and page
- `Screenshot 2024-08-03 175326.png` — Preview screenshot (shown above)
- `japan-background-digital-art (4).jpg` — Background image used in the demo

## Preview

Open `index.html` in your browser to view the form. The screenshot above shows the intended appearance.

## Usage

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-90.git

2. Open `index.html` in your browser, or serve the folder using a static server:

   - Double-click on `index.html`, or
   - Use VS Code Live Server or any static server and visit `http://localhost:5500` (or your chosen port)

3. Customize styles in `style.css` or replace the background image file.

## Customization Tips

- To change the background, replace `japan-background-digital-art (4).jpg` and update the filename in `style.css` if necessary.
- Edit colors, spacing, and font sizes in `style.css` to match your design.
- Hook the form to a backend API for real authentication—remember to perform server-side validation.
